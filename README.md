## Features/Modules

1. Chat Spammer - includes custom time control and staff evasion
2. Custom Age - Set your profile age outside the allowed range
3. Giphy Send - Exploits the giphyAPI to send your own messages without having upload permissions
4. Jebaiter - Another giphyAPI exploit, allowing the user to swap an image thumbnail and redirect to another, to bait people into clicking obscene messages
5. Character Bypass - Bypasses the configured maximum character limit in private messages
6. Anti Spam - Preconfigured filters for removing various types of spam from the DOM (guests, ads, etc)
7. Censor Bypass - Bypasses the word filter by using different characterset encodings
8. Quiz bot - Automatically plays the quiz - Includes staff evasion, custom timing, and changes the rate at which chat_log.php is called to get messages quicker
